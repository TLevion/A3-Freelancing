Assignment 3: Building Freelancing Experience Through Strategic Bidding
📌 Overview

This repository documents Assignment 3, which focuses on developing practical freelancing skills through strategic bidding on freelance platforms. The objective of this activity was to understand how freelancing marketplaces operate, improve proposal writing, organize a professional portfolio, and reflect on real-world challenges faced by beginner freelancers.

The assignment was completed over a 5-day period, with structured bidding, documentation, and reflection tasks.

🎯 Objectives

Learn how freelance platforms function

Create professional developer profiles

Practice writing customized project proposals

Improve GitHub portfolio presentation

Understand common freelancing challenges

Develop professional communication and self-reflection skills

🛠 Platforms Used

Freelancer.com

Truelancer

PeoplePerHour

⚠️ Note: Some platforms (e.g., Truelancer) require a paid membership to submit proposals, which affected proposal submission for certain projects.

✍️ Proposal Strategy

Each proposal:

Addressed the client’s project requirements

Highlighted relevant skills and academic background

Included GitHub portfolio links

Offered minimal charges to build experience

Proposed realistic timelines

Focused on limited and achievable scope

📊 Challenges Faced

High competition on freelance platforms

Some projects requiring paid memberships to apply

Vague or unclear project descriptions

No immediate feedback or interaction from clients

These challenges provided valuable insights into the realities of freelancing.

🧠 Key Learnings

Importance of customized proposals over generic templates

Value of a well-organized GitHub portfolio

Understanding platform-specific rules before bidding

Patience and consistency are essential in freelancing

Proposal writing is a critical professional skill
